# Mantou / Faith — aboutme

Personal portfolio merged from the Bun + Astro Echo implementation into [mantou-fw/aboutme](https://github.com/mantou-fw/aboutme). Existing target history, HTIFA, public contact information and `/about/` landing URL are preserved.

## Run with Bun

Requires Bun 1.3.14 or later.

```bash
bun install --frozen-lockfile
bun run check
bun run build
bun test
bun run start
```

The production entry is `dist/server/entry.mjs`, generated by the official `@astrojs/node` standalone adapter and **executed by Bun**. `start` explicitly runs `bun`, while `dev`, `check`, `build` and `preview` force Bun with `bun --bun`. This uses Bun's Node-compatible HTTP runtime. No Cloudflare Worker or Node process is required to run the site.

For development:

```bash
bun run dev --host 127.0.0.1 --port 4321 --ignore-lock
```

`GET /api/health` reports the actual runtime and Bun version. Tests start the real built server and verify that the runtime is `bun`.

## Hosting configuration

Set `SITE_URL` to the final public origin **before building**, so canonical URLs and sitemap are correct. No production domain has been supplied; the fallback is `http://localhost:4321` for local use.

```bash
SITE_URL=https://your-domain.example bun run build
HOST=0.0.0.0 PORT=4321 bun run start
```

Bun loads a local `.env` automatically; `.env.example` documents the settings. A hosting service or reverse proxy should run `bun run start` and forward traffic to `PORT`.

The old GitHub Pages workflow is replaced with Bun validation CI. GitHub Pages cannot execute a Bun server; pushing to main runs checks, build and tests, without publishing a static replacement or claiming a production deployment. No hosting provider was selected or deployed in this change.

## Pages and content

- `/` redirects to `/about/`, preserving the target's landing convention.
- `/about/`: supplied avatar, Mantou / Faith identity, selected projects and technology stack.
- `/profile/`: profile plus existing Founder, HTIFA / Taiwan information.
- `/projects/`: seven confirmed public GitHub projects plus existing HTIFA, with category filtering.
- `/projects/[slug]/`: details, source links and optional live links.
- `/sitemap.xml`, `/robots.txt`, `/api/health`: runtime endpoints.

`src/data/portfolio.json` is the current content source. `src/data/routes.ts` derives the page catalog for sitemap and tests. The existing public email is retained in the footer. Incoming fictional employers, demo articles, fake contribution numbers, generic X and JustOS links are not published.

The original target Astro components/data and incoming Echo recovery fixtures remain in source history. They do not create demo routes. `docs/specs/aboutme-bun-merge.md` records the merge intent; `docs/bun-merge-review.md` records validation. Prior screenshot reports describe earlier implementations and are historical evidence.
